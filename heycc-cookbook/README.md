# HeyCC Cookbook

[English](#english) | [简体中文](#中文)

## English

The Cookbook is a collection of runnable HeyCC usage, integration, and troubleshooting recipes—not a set of disconnected demos.

Every recipe should explain:

- the goal;
- prerequisites;
- minimal configuration;
- steps;
- expected results;
- common failure causes;
- permissions, platform limits, and security boundaries.
