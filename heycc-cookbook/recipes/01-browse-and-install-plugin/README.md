# Browse and Install a HeyCC Plugin

[English](#english) | [简体中文](#中文)

## English

### Goal

Browse plugins from HeyCC Settings and review their source and permissions before installation.

### Prerequisites

- A HeyCC version with plugin marketplace support;
- access to the public Marketplace;
- awareness of the plugin's author, source, license, and target platforms.

### Steps

1. Open HeyCC Settings and go to Plugins/Marketplace.
2. Open the plugin details and review its author, version, source, platforms, and requested permissions.
3. Check whether it requires a computer-side Companion, Bridge, or external service.
4. Install only after explicit confirmation; an install confirmation does not mean an external computer component is installed.
5. Return to the plugin details and inspect both plugin status and external dependency status.
6. If a dependency is not ready, follow the documented instructions and use a read-only re-check. Do not run an unknown script.

### Expected result

Plugin installation state and computer-side dependency state remain visible separately. A single “installed” message cannot make an external capability appear ready.

## 中文

### 目标

从 HeyCC 设置中的公开 Marketplace 浏览插件，理解来源和权限后再安装。

### 前置条件

- 已安装支持插件市场的 HeyCC 版本；
- 能访问公开 Marketplace；
- 了解插件的作者、来源、许可证和目标平台。

### 步骤

1. 打开 HeyCC 设置，进入 Plugins/Marketplace。
2. 打开插件详情，先查看作者、版本、来源、平台和请求的权限。
3. 确认插件是否有电脑端 Companion、Bridge 或外部服务依赖。
4. 明确同意后执行安装；安装提示不等于外部电脑组件已经安装。
5. 回到插件详情，检查插件状态和外部依赖状态。
6. 如果依赖未就绪，使用安装说明和只读重新检查，不执行来源不明的脚本。

### 预期结果

插件安装状态和电脑端依赖状态分别可见；用户不会因为一个“安装成功”提示误以为所有外部能力都已就绪。
