# Minimal HeyCC Plugin Template

[English](#english) | [简体中文](#中文)

## English

Copy this directory to `heycc-plugin/plugins/<plugin-id>/`, then:

1. Change `heyplugin.json`'s `name` to a stable kebab-case ID.
2. Add the real author, version, permissions, platforms, and README.
3. Add `skills`, `tools`, `quickActions`, or other supported contributions only as needed.
4. Add the corresponding entry to `marketplace.json`.
5. Before submitting, confirm that there are no secrets, private source code, arbitrary install commands, or arbitrary probe commands.

## 中文

复制此目录到 `heycc-plugin/plugins/<plugin-id>/`，然后：

1. 把 `heyplugin.json` 的 `name` 改成稳定的 kebab-case ID。
2. 补充真实作者、版本、权限、平台和 README。
3. 按需加入 `skills`、`tools`、`quickActions` 或其他受支持的贡献类型。
4. 在 `marketplace.json` 增加对应目录项。
5. 提交前确认没有密钥、私有源代码、任意安装命令或任意探测命令。
