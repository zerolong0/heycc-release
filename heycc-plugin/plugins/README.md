# Official Plugins

[English](#english) | [简体中文](#中文)

## English

This directory contains plugins maintained directly by HeyCC/ZeroX and eligible for official support.

Each plugin should include its own `heyplugin.json`, README, license, and relevant source notices. Before it enters the marketplace, it must pass static checks, permission review, platform documentation, and public-scope review.

The initial scaffold intentionally contains no unreviewed plugin implementation.

## 中文

这里放由 HeyCC/ZeroX 直接维护、能够接受官方支持的插件。

每个插件目录都应该包含自己的 `heyplugin.json`、README、许可证和必要的来源说明。加入市场目录前必须完成静态检查、权限审查、平台说明和公开发布范围确认。

初始骨架暂不添加未经审查的插件实现。
