# External Plugins

[English](#english) | [简体中文](#中文)

## English

This directory contains public entry points for community and partner plugins. Their authors maintain them; ZeroX does not replace the author or promise their stability and security.

Each entry should link to the author's repository, version, license, supported platforms, and changelog. Users should review the source and permissions before installation.

## 中文

这里记录社区或合作方插件的公开入口。社区插件由其作者维护，ZeroX 不代替作者承诺稳定性或安全性。

每个目录项至少需要链接到作者自己的仓库、版本、许可证、支持平台和变更记录。用户安装前应自行审查来源和权限。
