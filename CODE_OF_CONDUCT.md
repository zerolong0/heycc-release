# Code of Conduct

[English](#english) | [简体中文](#中文)

## English

We want HeyCC's public channel to be friendly, concrete, respectful, and collaborative.

When participating in an Issue, Discussion, Pull Request, or plugin review:

- discuss the problem and code, not the person;
- provide facts, reproduction steps, and evidence;
- respect different experience levels, platforms, and use cases;
- do not publish private data, secrets, malicious code, or unauthorized third-party content.

Maintainers may remove unsafe, harassing, or clearly out-of-scope content.

## 中文

我们希望 HeyCC 的公开频道保持友善、具体、尊重和可协作。

参与 Issue、Discussion、Pull Request 或插件评审时，请：

- 针对问题和代码，不针对个人；
- 说明事实、复现步骤和证据；
- 尊重不同经验、平台和使用场景；
- 不发布隐私、密钥、恶意代码或未经授权的第三方内容。

维护者可以移除不安全、骚扰性或明显不符合本项目范围的内容。
